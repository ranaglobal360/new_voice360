Notes
Rules that apply across every flow
State is never lost
Back from any step in B, C or D returns with all entered data. Killing the app mid-request restores via FR-08.1D Resume draft.
Offline is global
FR-07.6O can surface on any screen. Retry resumes in place — it never restarts a flow. Never fire a payment twice on retry.
Processing is uncancellable
FR-07.5 blocks back and gestures. Timeout (FR-07.5T) polls the gateway; only a definite result routes to 06 or 07.
One payment component
FR-07.3/05 and FR-09.3 are the same module with a recurring flag. Build once.
Recurring events are push-first
FR-09.5F and FR-08.5C arrive as notifications and deep-link straight to the screen shown here.
Money is always traceable
Every donation and every withdrawal lands in the public ledger (FR-05 → FR-05.D). No silent transfers.
Roles gate FR-13 only
A–G are open to any signed-in user. H requires an approved organiser record from C.
Empty ≠ error
FR-10.4 and FR-02.N are empty states with a forward action, not failures. Do not show error styling.
